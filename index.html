Cloud architecture

Reference architectures on AWS and GCP

Patterns I've designed and run, from edge delivery and identity to event-driven sync and ML platforms. Pick a pattern to trace the flow.

VPS first

A single Coolify VPS with Docker Compose runs a whole early-stage product for a fraction of hyperscaler cost. Fitvive stays there until roughly 200K–300K monthly users.

When to move

A fully managed cloud stack can cost 14–20× a VPS. The move pays off when SLAs, multi-region, auto-scaling or compliance actually show up.

AWS vs GCP

For VM-based setups the two land within a few percent. GCP's e2 instances with committed use edge ahead on compute; AWS gp3 is cheaper on block storage.
